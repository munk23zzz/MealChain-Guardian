## Brand & Style

The design system is constructed for mission-critical cold-chain logistics, food safety auditing, and autonomous supply chain operations. The audience comprises procurement directors, regional nutritionists, cold-chain logistics operators, and compliance monitors who evaluate high-velocity telemetry under pressure.

The UI embodies an operational philosophy:
- **Absolute Precision:** Every metric, ledger line, and sensory reading must communicate certainty and provenance.
- **Calm Under Stress:** Deep emerald tones establish baseline compliance and stability, keeping visual strain low during extended operational shifts.
- **Surgical Hierarchy:** Critical anomalies, temperature excursions, and supply disruptions surface through stark contrast, avoiding ambient noise or decorative distraction.

The visual execution is a refined **Corporate/Data-Dense Console** aesthetic, influenced by mission-control telemetry and high-assurance financial ledgers. Crisp hairline borders, compact data density, structured grid alignments, and high-contrast monospaced telemetry blocks ensure zero cognitive friction when triaging safety events.

## Colors

The color architecture balances operational calm against acute safety alerts:

- **Primary (`#0F766E` - Deep Emerald Teal):** Denotes verified compliance, cold-chain safety integrity, and confirmed batch routing. It acts as the grounding tone for primary actions, structural status indicators, and validated ledger verifications.
- **Secondary (`#D97706` - Warm Amber/Orange):** Flags supply bottlenecks, imminent stock dry-out, delivery delays, and tight threshold deviations before they deteriorate into spoilage.
- **Tertiary (`#DC2626` - Crimson Red):** Reserved exclusively for hard safety violations, temperature excursions above critical thresholds, broken tamper seals, and blocked consensus proposals.
- **Neutral (`#64748B` - Slate Neutral):** Provides balanced typographic scale, metadata timestamps, table headers, and structural lines across light canvas surfaces.

### Surface System
- Canvas background rests at `#F8FAFC`, avoiding glare while cleanly separating white `#FFFFFF` cards and audit tables.
- The telemetry terminal and agent trace environments leverage `#0F172A` as an immutable inspection backdrop, paired with `#2DD4BF` for real-time pipeline tokens and live payload tracing.

## Typography

The typographic hierarchy establishes distinct functional roles:
- **Inter** handles narrative communication, form inputs, status labels, action triggers, and executive overviews. Its balanced x-height ensures readability across high-density tables and compact split panes.
- **JetBrains Mono** governs sensory telemetry, cryptographically hashed ledger references, JSON payloads, timecodes, latitude/longitude coordinates, and price-per-kilogram indices. It enforces tabular column alignment across live metrics.

Rules for typography usage:
- Ledger hashes and device IDs must always use `code-sm` or `code-md`.
- KPI delta tags and numerical indices default to tabular lining numbers in Inter or JetBrains Mono.
- Uppercase styling is restricted to micro-labels, state badges (`code-sm` or `label-sm`), and table column headers with `letterSpacing: 0.05em`.

## Layout & Spacing

This design system uses an **adaptable column grid** calibrated for data-dense dashboards:
- **Desktop (1280px+):** Fixed 260px navigation sidebar, fixed 64px global monitoring header, and a 12-column fluid grid with `1rem` gutters and `1.5rem` outer canvas padding. Split view panels (e.g., Map on the left, Telemetry list on the right) lock to a 60/40 or 50/50 split with zero outer bleed.
- **Tablet (768px - 1279px):** Sidebar collapses to an icon rail (64px width); 8-column layout with `0.75rem` gutters. Multi-step timeline visualizers convert to scrollable horizontal lanes.
- **Mobile (< 768px):** Single-column vertical reflow; top-pinned location scope picker; outer margin reduced to `1rem`. Secondary telemetry panes collapse beneath action recommendation cards.

Rhythm and alignment follow a rigid 4px and 8px base grid. Tight `0.5rem` and `0.75rem` internal card padding are prioritized over expansive whitespace to maximize the vertical visibility of data tables, evidence chains, and decision feeds without requiring excessive scrolling.

## Elevation & Depth

The design system minimizes dramatic shadow casting in favor of **structural containment and low-contrast surface borders**. Depth signifies actionable focus and state overlay rather than physical skew:

- **Base Surfaces (`Level 0`):** Canvas background (`#F8FAFC`). Pure flat geometry.
- **Card and Data Surfaces (`Level 1`):** Pure white cards (`#FFFFFF`) framed with a crisp `1px solid #E2E8F0` border and an ambient low-profile shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`.
- **Interactive Focus & Hover Tiers (`Level 2`):** Elevates actionable recommendation cards and table row hovers with `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)` and subtle border darkening to `#CBD5E1`.
- **Modals, Flyouts & Slide-in Ledgers (`Level 3`):** Context panels and decision detail drawers utilize `0 10px 15px -3px rgba(15, 23, 42, 0.1), 0 4px 6px -4px rgba(15, 23, 42, 0.06)` combined with a 50% opacity backdrop `#0F172A` overlay.
- **Observability Console Tier:** Dark console panels (`#0F172A`) utilize no drop-shadows; they are inset-framed with `#1E293B` hairline strokes to emphasize an encapsulated terminal container.

## Shapes

The design system applies a **Soft geometric language (Level 1)**:
- Standard elements (buttons, inputs, status badges, table containers, telemetry cards) utilize `0.25rem` (4px) corner radii.
- Large contextual wrappers, modal dialogues, and root layout cards use `0.5rem` (8px).
- Status indicator pills and live pipeline step nodes use full circular or pill framing (`9999px`) to maintain immediate visual distinction from rectangular structural blocks.

This controlled roundedness conveys institutional rigor, maximizing usable screen surface and reinforcing the authoritative nature of cold-chain compliance data.

## Components

### Buttons
- **Primary Action (Approve / Execute):** Background `#0F766E`, text `#FFFFFF`, border `1px solid #0D655E`, corner radius `4px`, font `label-md`. Hover: `#115E59`. Active: `#134E4A`.
- **Warning / Exception Action:** Background `#D97706`, text `#FFFFFF`, border `1px solid #B45309`, font `label-md`. Hover: `#B45309`.
- **Destructive / Reject Action:** Background `#FFFFFF`, text `#DC2626`, border `1px solid #FCA5A5`, font `label-md`. Hover: `#FEF2F2`.
- **Ghost / Neutral Action:** Background transparent, text `#334155`, border `1px solid #CBD5E1`, font `label-md`. Hover: `#F1F5F9`.
- **Disabled State:** Background `#F1F5F9`, text `#94A3B8`, border `1px solid #E2E8F0`, cursor not-allowed.

### Status Badges & Chips
- Compact padding (`2px 8px`), font `label-sm` or `code-sm`, border-radius `4px`.
- **Safe / Compliant:** Background `#ECFDF5`, text `#065F46`, border `1px solid #A7F3D0`.
- **Warning / Tight Supply:** Background `#FFFBEB`, text `#92400E`, border `1px solid #FDE68A`.
- **Critical Excursion / Failure:** Background `#FEF2F2`, text `#991B1B`, border `1px solid #FECACA`.
- **Role Scoping Chips:** Background `#F8FAFC`, text `#334155`, border `1px solid #CBD5E1` with user privilege icons.

### Input Fields & Selectors
- Background `#FFFFFF`, height `36px`, padding `0 12px`, border `1px solid #CBD5E1`, border-radius `4px`, font `body-md`.
- Focus ring: `2px solid #0F766E` with an offset of `1px`.
- Monospace Data Inputs (e.g., threshold overrides, lot IDs): Rendered in `code-md`.

### Cards & Container Panels
- Background `#FFFFFF`, border `1px solid #E2E8F0`, border-radius `6px`, padding `16px`.
- Header section separates cleanly with a `1px solid #F1F5F9` bottom dividing line, holding title, badge, and contextual menu triggers.

### Data Tables (Evidence & Commodities)
- Alternating row styling: standard rows `#FFFFFF`, hover state `#F8FAFC`.
- Column header: height `32px`, background `#F8FAFC`, text `#64748B`, font `label-sm`, uppercase, letter spacing `0.05em`, border bottom `1px solid #CBD5E1`.
- Row height: dense `40px`, numeric data right-aligned using `JetBrains Mono`.

### Specialized Domain Components
- **Agent Pipeline Stepper:** Linear node flow (`DETECT` ➔ `VERIFY` ➔ `TRACE` ➔ `PREDICT` ➔ `OPTIMIZE` ➔ `DECIDE` ➔ `ACT` ➔ `LEARN`) connected by 2px hairline rails. Active steps render with `#2DD4BF` pulsing outlines; completed steps render solid `#0F766E`; pending steps render muted slate `#94A3B8`.
- **Cold-Chain Trace Ledger Panel:** Encapsulated terminal component with `#0F172A` background, `#1E293B` borders, monospaced text (`code-md`), and integrated copy-to-clipboard actions for cryptographic block signatures and IoT sensor hashes.
- **Metric KPI Callout Widget:** Dual-layer layout featuring large tabular numeric values (`display` or `headline-lg`) paired with delta trend badges (e.g., `+2.4% vs safe baseline`) and sparkline baseline charts.
